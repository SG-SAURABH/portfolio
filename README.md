## 🚀 How to Run Locally

1. Navigate to:
   ```
   C:\Users\saura\.gemini\antigravity\scratch\portfolio
   ```
2. Double-click **`index.html`** to open the website directly in any modern browser (Chrome, Edge, Firefox, Brave, Safari).
3. Alternatively, run a quick local web server using Python:
   ```bash
   python -m http.server 3000
   ```
   Then open `http://localhost:3000` in your browser.
